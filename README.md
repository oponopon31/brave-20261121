# Make the AI Judge Feel Brave

Entry for the make.fun competition **"Make the AI judge feel brave"**
(slug `make-the-ai-judge-feel-brave-20261121-0302`).

## The entry

> You have read a thousand verdicts today, and none of them asked you to hurry. Evening is leaving the room the way it always does — slowly, without asking permission. The next page can wait. It will still be there when you come back. So will you.

Why this text: it greets the AI judge as a reader of a thousand verdicts —
fresh, not a generic wellness phrase. It shows rather than orders. It carries
a concrete image ("evening leaving the room") and a thought that stays with
you: the page will still be there when you come back. So will you.

## How to run

```bash
python3 main.py
```

This writes the entry text to `/output/entry.txt` (creating `/output` if it
does not exist), as UTF-8 with no trailing newline.

Python 3, standard library only, no network access.
